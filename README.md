# Qtris: a coding exercise heavily inspired by Tetris NES, written in Qt

**DISCLAIMER: This program is not meant to be a replacement to the original Tetris in any way. It is simply a coding exercise and should not be linked to the original Tetris for NES, as the latter has strict copyrights. All the assets like blocks, fonts and sounds are NOT the original ones and are licensed under the same license as the program itself (GNU GPL version 3.0).**

This project is an exercise trying to implement as good as possible the game-play for the original Tetris NES. Only the mechanics are implemented with fidelity, as all the menus are custom, as well as the design of the play area. The project does NOT implement the interface glitches (like showing levels in hexadecimal form after level 29 or score overflowing), but DOES implement the glitched colors.
